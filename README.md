# Portfolio Website — Ifrah Kausar

A clean, responsive, and modern portfolio website showcasing the profile, background, and skills of **Ifrah Kausar**, an aspiring Linux Systems Specialist. Built with raw HTML and CSS, featuring a dark-themed UI and terminal-inspired design elements.

---

## 🌟 Overview

This single-page portfolio highlights expertise across Linux systems, networking, IT infrastructure, and professional experience. It includes interactive navigation, a simulated command-line interface section, and direct links to professional profiles.
